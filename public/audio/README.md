# 音声ファイル配置ディレクトリ

BGM・SE・VOICE の音源を配置するディレクトリです。ファイルパスは `src/bgm.ts`（BGM）および `src/se.ts`（SE・VOICE）に登録されています。

## BGM（`src/bgm.ts`）

以下のファイル名で配置すると、場面に応じて自動的にループ再生されます（MP3推奨）。`/audio/` に無い場合は `public/` 直下の同名ファイルをフォールバックとして参照します。

| ファイル名 | 再生される場面 |
| --- | --- |
| `bgm_opening.mp3` | 777揃い後の BONUS GET 演出 |
| `bgm_pre_battle.mp3` | 雑魚戦・小役ゲーム（BET待ち・レバー待ち・リール回転中） |
| `bgm_battle.mp3` | BATTLE MODE（突入演出・バトルパート全8G・結果告知） |
| `bgm_gameover.mp3` | GAME OVER 後からリトライまで |

- 777揃え（BONUS確定）中はBGMを鳴らさず、SEのみ再生します。
- 設定画面を開いている間はBGM音量を半分に下げます。

## SE・VOICE（`src/se.ts`）

`se_*.wav`（効果音）と `voice_*.wav`（ボイス）を配置します。新しい音源を追加する場合は `src/se.ts` の登録表にキーとパスを追加してください。

## 共通事項

- ファイルがまだ配置されていない状態でも、ゲーム本体は該当音声を鳴らさずに正常にプレイできます。
- ブラウザの仕様（Autoplay Policy）により、画面を1回タップ／クリックした時点で再生が開始されます。
- 音源の追加・差し替え時は [アセット可逆圧縮・最適化仕様](../../docs/assets-compression-spec.md) に従ってください。
